# Israf Guard

**Turn Food Waste Into Opportunity.**

Israf Guard is a concept/prototype website for an intelligent food-waste management platform for universities, cafeterias, restaurants, and food vendors. It predicts demand, reduces waste, increases vendor profit, and connects surplus food with students through closing-time discounts.

## What's here

A single self-contained `index.html` (no build step, no dependencies) covering:

- Brand identity and a custom SVG logo mark (steaming rice bowl)
- Problem / solution narrative with an interactive Predict → Learn → Redeem → Return cycle
- A vendor intelligence dashboard prototype with animated hand-built SVG charts
- Smart pricing and best-seller/profit-intelligence tools
- A student mobile-app mockup and campus vendor map
- Sustainability badges, environmental impact metrics, and a university-ecosystem view
- An admin/university dashboard with a vendor sustainability leaderboard
- A roadmap and final call-to-action

## Running it locally

It's a static file — just open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Stack

Vanilla HTML, CSS, and JavaScript. No frameworks, no build tools, no external chart libraries — all charts are hand-built inline SVG. Fonts are loaded from Google Fonts (Space Grotesk + Inter).
